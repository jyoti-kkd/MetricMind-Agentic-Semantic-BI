# MetricMind-Agentic-Semantic-BI

## Overview

MetricMind is an Agentic Semantic BI Engine that allows users to ask business questions in natural language and receive data-driven insights through a governed semantic layer.

## Project Goal

The goal of MetricMind is to connect business users with trusted analytical data using semantic modeling, agentic AI, and conversational business intelligence.

## Technology Stack

- Semantic Layer: Cube.dev / dbt Semantic Layer
- AI Agent / Orchestrator: LangChain / Llama 3
- Data Warehouse: Snowflake / Databricks
- Data Modeling: dbt
- Frontend: Next.js
- UI Components: Tremor
- Visualization: ECharts

## Project Structure

- `data/` - Mock corporate datasets
- `snowflake/` - Snowflake database and SQL scripts
- `dbt/` - dbt data transformation models
- `docs/` - Project documentation

## Development Plan

The project is developed in four phases:

1. Data Modeling & Semantic Foundation
2. Semantic Layer + Agentic AI
3. Conversational BI + Dynamic Visualization
4. Advanced Reasoning, Governance & Finalization
